# myDAY

一个轻量的 macOS 四象限待办应用。

`myDAY` 用四象限把当天要做的事放在桌面上：重要紧急、重要不紧急、不重要紧急、不重要不紧急。它支持普通窗口模式和桌面常驻模式，适合把今日任务保持在视野里，又不打断当前工作。

## 主要功能

- 四象限待办管理。
- 点击空白区域快速新增任务。
- 按回车连续新增任务。
- 任务完成后进入当天已完成列表。
- 更早完成的任务自动折叠。
- 支持任务拖拽排序和跨象限移动。
- 支持拖动中心圆点调整四象限比例，双击恢复居中。
- 支持页面透明度调整。
- 支持正常窗口模式和桌面常驻模式切换。
- 支持菜单栏入口和全局快捷键设置。

## 安装

下载最新版：

https://github.com/QianYushi/myDAY/releases/latest

然后：

1. 打开 `myDAY.dmg`。
2. 把 `myDAY.app` 拖到“应用程序”。
3. 启动 `myDAY`。

第一次打开时，macOS 可能会提示该应用来自互联网。请在系统设置中允许打开，或右键点击应用后选择“打开”。

## 使用

打开后，`myDAY` 会出现在菜单栏，并显示四象限主窗口。

- 点击象限空白处：新增任务。
- 回车：保存当前任务并继续新增下一条。
- 失去焦点：有内容则保存，空任务则撤回。
- 点击任务前的方框：完成或取消完成。
- 拖动任务：调整同一象限内顺序，或移动到其他象限。
- 拖动中心圆点：调整四象限比例。
- 双击中心圆点：恢复居中。
- 顶栏圆点：切换桌面常驻模式和正常窗口模式。
- 菜单栏图标：打开菜单，可展示到前台、隐藏窗口、设置快捷键、查看关于应用或退出。

## 数据

`myDAY` 是本地应用。待办数据保存在本机 `UserDefaults` 中，不会上传到服务器。

## 系统要求

- macOS 13 Ventura 或更高版本。

## 说明

`myDAY` 不是 Mac App Store 应用。当前发布版用于个人本地使用，没有做 App Store 分发。
